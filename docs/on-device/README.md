# On-device documentation

Companion firmware for the Artillery M1 Pro X1 S1-SOC (RK3308BS). Additional guides are in this folder.

## Login credentials

Change passwords after first boot.

| Account | Username | Password |
|---------|----------|----------|
| Normal user | `m1prox1` | `m1prox1` |
| Root | `root` | `m1prox1` |

WiFi is **not** pre-configured on the published image.
